# Лексикон

Веб-приложение (PWA) для iPhone: учить английские слова, не добавляя их вручную.

- **Подбор** — приложение само предлагает 20 слов твоего уровня (A2–C1), с транскрипцией, переводом, примером и озвучкой. Отмечаешь нужные, остальные можно заменить, лишние отметить «знаю» — они больше не появятся. Отмеченные сохраняются как набор. Новый набор можно собрать в любой момент.
- **Свои слова** — «Подбор → Добавить свои слова». Пишешь слово, и перевод, транскрипция и пример подставляются сами: сначала из встроенного словаря, затем от Claude (если есть ключ), иначе из бесплатных Free Dictionary и MyMemory. Всё можно поправить перед сохранением. Можно вставить список или выбрать файл (.txt/.csv, подходит экспорт из Quizlet): по слову в строке, перевод — через Tab, « - », «;» или «=».
- **Тренировка** — карточки (переворот и свайп), тест в обе стороны (EN→RU и RU→EN) и письмо. Смешанный режим подбирает упражнение по тому, насколько хорошо ты знаешь слово.
- **Интервальное повторение** — пять ступеней (Лейтнер): верный ответ отодвигает слово на 1, 2, 4, 8 дней, ошибка возвращает его в начало. «Сегодня» показывает, что пора повторить.
- **Трекер** — серия дней, календарь, график верных ответов за 14 дней. День засчитывается, когда набрана дневная цель (по умолчанию 20 верных ответов).
- **Работает без интернета.** Встроенный словарь — 1887 слов: A2 194, B1 204, B2 1006, C1 483 (≈95 полных наборов). С ключом Claude слова подбираются на любую тему.

Все данные хранятся только на устройстве. В настройках есть резервная копия (сохранить и восстановить JSON).

## Запуск на Mac

```bash
npm install
```

```bash
npm run dev
```

Откроется на http://localhost:5173. Проверка и сборка:

```bash
npm test
```

```bash
npm run build && npm run preview
```

## Установка на iPhone

Приложение опубликовано на GitHub Pages: **https://detector1997.github.io/leksikon/**

На iPhone открой этот адрес в Safari → «Поделиться» → «На экран „Домой“» → «Добавить».

Выложить новую версию после изменений:

```bash
npm run deploy
```

Команда прогоняет тесты, собирает приложение и публикует папку `dist` в ветку `gh-pages`. Установленное на iPhone приложение подтянет обновление при следующем запуске с интернетом.

Настоящего виджета на домашнем экране у веб-приложения быть не может — iOS даёт виджеты только нативным приложениям. Будет иконка приложения.

## Ключ Claude (необязательно)

Создай ключ на console.anthropic.com и вставь в «Настройки → Ключ Claude». Ключ хранится только на телефоне и не попадает в резервную копию. В «Подборе» появится тема «Своя»: можно написать что угодно («собеседование в IT», «футбол») — Claude подберёт 20 слов. Один набор стоит около 4 центов.

## Источники слов

Большая часть слов B2 и C1 отобрана из открытых списков с уровнями CEFR, переводы, транскрипции и примеры написаны отдельно:

- The CEFR-J Wordlist Version 1.5. Compiled by Yukio Tono, Tokyo University of Foreign Studies (via Open Language Profiles). Разрешено использовать бесплатно, в том числе в коммерческих целях, со ссылкой на источник.
- Octanove Vocabulary Profile C1/C2 (ver 1.0), Octanove Labs — CC BY-SA 4.0. Поэтому `public/data/words-c1.json` распространяется на тех же условиях, CC BY-SA 4.0.

Подробнее — в `public/data/SOURCES.md`.

## Устройство

- `src/screens` — экраны: Сегодня, Подбор, Набор, Трекер, Настройки
- `src/train` — тренировка: карточки, тест, письмо
- `src/lib` — логика: интервальное повторение, серия, подбор слов, хранилище (IndexedDB)
- `src/ai/generateWords.ts` — подбор слов через Claude (загружается только при запросе)
- `public/data/words-*.json` — встроенный словарь; `npm test` проверяет его на дубли и пустые поля
- `scripts/make-icons.mjs` — генерирует иконку из контуров шрифта (`npm run icons`)
