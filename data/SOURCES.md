# Word bank sources

Each file is a JSON array of rows: `[en, ipa, pos, ru, example, exampleRu, topic]`.
Russian translations, IPA, example sentences and topics were written for this app.

Headword selection draws on:

- **The CEFR-J Wordlist Version 1.5.** Compiled by Yukio Tono, Tokyo University of Foreign Studies.
  Retrieved via Open Language Profiles (github.com/openlanguageprofiles/olp-en-cefrj).
  Free for research and commercial use, provided the dataset is cited. Copyright: Tono Laboratory, TUFS.
  Used for the B2 additions in `words-b2.json`.
- **Octanove Vocabulary Profile C1/C2 (ver 1.0).** Octanove Labs.
  Licensed under Creative Commons Attribution-ShareAlike 4.0 International (CC BY-SA 4.0).
  Used for the C1 additions in `words-c1.json`; that file is therefore shared under CC BY-SA 4.0.

The remaining A2–C1 entries were selected by hand for the first version of the app.
